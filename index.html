About Me

WHO I AM

I'm a creative technologist based in Nigeria, building software across domains — Discord ecosystem, web platforms, automation systems, APIs. If the problem is real and the build is worth shipping, I'm in.

Python is my primary language — it just works, every time. JavaScript covers the web and frontend layer. Together they handle almost everything I need to build.

I don't limit myself to one niche. I've built full web projects with auth flows and databases, containerised apps with Docker, real-time systems with Firebase, custom coding trackers, and deployed production APIs. The stack changes with the problem.

Right now my biggest build is SimCoin V2 — a full-scale Discord economy RPG with 100+ commands and a fictional city called Simora. It's the project that levelled everything up.

How I work: I move fast, ship early, and iterate. I know my tools well enough to pick the right one without thinking — and when I don't know something, I figure it out.
